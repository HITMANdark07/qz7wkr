UK Wind Forecast Monitor

A web app for a UK utility's day-ahead trading desk, covering purchase decisions made in January 2026.

The trader's question

power to buy on the day-ahead market ≈ demand − expected wind

Wind is set by the weather, so the trader has to rely on a forecast. The app answers two questions:

  1. What wind forecast did I have when I had to decide? That is the latest forecast published before the cutoff.
  2. How far can I trust it? The forecast's error measured against actual output, in MW, so the desk can size a safety buffer.

Data: Elexon BMRS only. Actuals come from FUELHH (fuelType = WIND, every 30 min). Forecasts come from WINDFOR (startTime + publishTime).

How the "latest available forecast" is picked

Elexon publishes many forecasts for the same half-hour. For delivery day D, the app keeps only forecasts that existed at the decision time, and takes the newest of them for each target time.

ModeRuleWhy
Day-ahead (default)Newest forecast with publishTime ≤ 11:00 UK time on D-1Matches the real GB day-ahead auction gate
Horizon (slider 1–48h)Newest forecast with publishTime ≤ startTime − H hours"How good is a forecast made H hours ahead?"

Scope: decisions made 1–31 Jan 2026 → delivery days 2 Jan–1 Feb 2026, using forecasts published from 30 Dec 2025 onward. Forecasts are compared with actuals only where their timestamps match.

Architecture

1 · Ingest (run once)

scripts/fetch_data.py
  • Calls the Elexon FUELHH and WINDFOR stream APIs
  • Filters to WIND and the January window
  • Saves compact files to backend/data/

2 · Backend (Python)

FastAPI
  • analytics.py: forecast selection and metrics (pandas)
  • GET /api/day?date&mode&horizon
  • GET /api/accuracy?mode&horizon
  • GET /api/meta
  • pytest unit tests

3 · Frontend (React)

Vite + TypeScript + Recharts
  • Controls, KPI tiles, 4 charts
  • Calls /api/* on the same domain

4 · Run & deploy

  • Docker: docker-compose (api + web)
  • Vercel: static React build + FastAPI as a Python serverless function
  • GitHub Actions runs pytest
